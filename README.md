# Materiali didattica — bottantonio.com

Lezioni pratiche, esercizi e verifiche, pubblicati come allegati
scaricabili dalla pagina [Didattica](https://bottantonio.com/didattica/)
di [bottantonio.com](https://bottantonio.com).

Organizzati per **argomento**, non per classe/sezione, in percorsi
progressivi dalle basi a un livello più avanzato:

- `servizi-commerciali/html-css/` — percorso HTML (6 lezioni): dal primo
  documento HTML ai tag semantici
- `servizi-commerciali/css/` — percorso CSS (8 lezioni): da selettori e
  box model a Flexbox, Grid, responsive design e animazioni
- `tecnico-economico/database/` — percorso Database (14 lezioni): dal
  concetto di database e DBMS, al modello Entità-Relazione, fino alla
  traduzione in tabelle relazionali
- `liceo/` — appunti di C++ (array, funzioni/ricorsione, puntatori/struct/liste)

Ogni PDF è materiale originale e generico: teoria, schema visivo,
codice di esempio dove pertinente, un caso d'uso pratico ed esercizi
di riepilogo. Nessun riferimento a classi, sezioni o istituti
scolastici specifici.
